# 普陀中学摄影社官网

Website of Photography Club of Putuo High School（普陀中学摄影社官方网站）

🌐 线上地址：<https://kylinle.github.io/pcpths/>

## 关于本站

摄影社官方静态网站，采用 **细线 / 黑白 / 字距** 的极简设计，全站统一设计语言。包含：

- **首页**：首屏（"留住光"）、课程介绍、任务与活动、后续摄影计划、APP 下载（安卓版直接下载 pcpths_android.apk 并弹窗提示；苹果版弹窗提醒需用 Safari，确定后下载并进入安装指南页）；顶栏下方有"拍摄计划更新"通知栏，点击直达后续计划，可一键关闭
- **计划分页**：元旦各社团祝福拍摄、元旦晚会拍摄与录制
- 移动端自适应、滚动显现动画、毛玻璃导航栏

## 设计规范：细线

细线是全站视觉骨架的核心元素。总原则：**美观为先，宁缺毋滥，不得过度使用**。

### 颜色原则

| 颜色 | 用途 |
|------|------|
| **浅灰 `#e3e3e5`**（变量 `--line`） | **为主**。所有结构性分隔都用它 |
| **纯黑 `#0f0f0f`**（变量 `--ink`） | **克制**。仅限以下三处强调，不得新增其他用途 |

### 使用范围

| 位置 | 颜色 | 说明 |
|------|------|------|
| 分节之间（`.sec` 顶部） | 浅灰 | 分隔相邻模块 |
| 列表行之间（`.list-item` 底部） | 浅灰 | 行与行的分隔 |
| 导航栏底边（滚动后显现） | 浅灰 | 提示导航状态 |
| 页脚 / 底栏顶边 | 浅灰 | 页面收尾 |
| 手机菜单顶边与菜单项之间 | 浅灰 | 菜单结构 |
| 通知栏内分隔与 × 线条（`.notice`，黑底） | 白色 18% / 白色 | 黑底上的浅色结构线（白底浅灰线的反相） |
| 弹窗边框（`.modal-box`） | 浅灰 | 弹窗结构分隔 |
| 列表 / 模块顶部起始线（`.list`、`.courses`） | 纯黑 | 强调：模块内容从这里开始 |
| 按钮描边（"上课平台"、"进入"） | 纯黑 | 强调：提示可点击 |
| 链接悬停下划线（导航链接、计划条目） | 纯黑 | 强调：交互反馈 |

### 方法（三条铁律）

1. **只用 1px**——任何情况下不加粗、不使用虚线或多重边框
2. **同方向不叠线**——两条横线之间必须留有足够间距，禁止出现近距"双线"（例如标题被上下两线夹住，即为反例，已修除）
3. **拿不准就用浅灰**——纯黑线只允许出现在上表列出的三处强调位；新增设计时先想"这条线是否必要"，多余即删

### 分页面的特殊约定

计划分页（`plan/`）的内容区不设上下框线，直接以留白分隔，保持轻盈；主页各模块维持原设计。

## 发布方式

本仓库使用 **GitHub Pages** 从 `main` 分支根目录自动部署：

1. 修改本地文件并提交
2. 推送到 `main` 分支
3. 网站约 1–2 分钟内自动更新（无需任何手动操作）

## 技术说明

- 纯静态 HTML/CSS/JS，无框架、无构建步骤，任何编辑器均可修改
- 所有分页面复用主页的样式与组件，改一处样式全站生效
- 使用相对路径引用资源，域名或路径变更不影响页面
