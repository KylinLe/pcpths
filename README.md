# 普陀中学摄影社官网

Website of Photography Club of Putuo High School（普陀中学摄影社官方网站）

🌐 线上地址：<https://kylinle.github.io/pcpths/>

## 关于本站

摄影社官方静态网站，采用 **细线 / 黑白 / 字距** 的极简设计，全站统一设计语言。包含：

- **首页**：首屏（"留住光"）、课程介绍、任务与活动、后续摄影计划、APP 下载板块（安卓 / 苹果双按钮并排；安卓直接下载 pcpths_android.apk 并弹窗提示，苹果弹窗提醒需用 Safari、确定后下载并进入安装指南页）、测试一（测试用，含文章「测试」）；顶栏下方通知栏可多条堆叠（"普陀中学摄影社 APP 已上线"→前往下载 / "拍摄计划更新"→直达后续计划），各自关闭后同浏览器不再显示，顶栏「通知」入口可重新显示全部并重播滑入动画作为弹出反馈
- **计划分页**：元旦各社团祝福拍摄、元旦晚会拍摄与录制
- **安卓 App 联动**：首页与计划页内容自动同步给原生安卓 App（见下方联动约定）
- 移动端自适应、滚动显现动画、毛玻璃导航栏

## 与安卓 App 的联动约定

本站内容同时供**原生安卓 App**（普陀中学摄影社 App）自动同步：App 启动或刷新时抓取首页和 `plan/` 计划说明页，翻译成原生界面展示；底部导航标签由官网栏目自动生成，栏目链接文字即标签名（请控制在 2~4 个字）。

- **自动适配（照常做）**：标准分节栏目、计划说明页、通知条的新增修改，以及列表 / 课程卡片 / 岗位表等组件内的文字增删改
- **App 认识的组件**：分节 `sec`、列表 `list`、课程卡片 `courses`、岗位表 `spec-table`（行需保留 `data-label`）、通知条 `notice`、首屏 `hero`
- **需协调升级 App（禁止悄悄上线）**：发明清单外的全新组件或排版、改变现有组件的结构含义（class 名、锚点 id、页面组织方式）。须先报告协调，App 升级后再一起上线
- **其他**：锚点 id（`courses`、`missions`、`plans`）保持稳定；禁止内联样式；设计语言（细线 / 黑白 / 字距 / 六边形光孔）不变
- App 不展示顶部导航栏、04 APP 下载板块、上课平台入口、页脚与弹窗，改动这些不影响 App

完整约定见 `CLAUDE.md`。

## 设计规范：细线

细线是全站视觉骨架的核心元素。总原则：**美观为先，宁缺毋滥，不得过度使用**。

### 颜色原则

| 颜色 | 用途 |
|------|------|
| **浅灰 `#e3e3e5`**（变量 `--line`） | **为主**。所有结构性分隔都用它 |
| **纯黑 `#0f0f0f`**（变量 `--ink`） | **克制**。仅限以下三处强调，不得新增其他用途 |

### 使用范围

| 位置 | 颜色 | 说明 |
|------|------|------|
| 分节之间（`.sec` 顶部） | 浅灰 | 分隔相邻模块 |
| 列表行之间（`.list-item` 底部） | 浅灰 | 行与行的分隔 |
| 导航栏底边（滚动后显现） | 浅灰 | 提示导航状态 |
| 页脚 / 底栏顶边 | 浅灰 | 页面收尾 |
| 手机菜单顶边与菜单项之间 | 浅灰 | 菜单结构 |
| 通知栏内分隔与 × 线条（`.notices`，黑底） | 白色 18% / 白色 | 黑底上的浅色结构线（白底浅灰线的反相） |
| 弹窗边框（`.modal-box`） | 浅灰 | 弹窗结构分隔 |
| 列表 / 模块顶部起始线（`.list`、`.courses`） | 纯黑 | 强调：模块内容从这里开始 |
| 按钮描边（"上课平台"、"进入"） | 纯黑 | 强调：提示可点击 |
| 链接悬停下划线（导航链接、计划条目） | 纯黑 | 强调：交互反馈 |

### 方法（三条铁律）

1. **只用 1px**——任何情况下不加粗、不使用虚线或多重边框
2. **同方向不叠线**——两条横线之间必须留有足够间距，禁止出现近距"双线"（例如标题被上下两线夹住，即为反例，已修除）
3. **拿不准就用浅灰**——纯黑线只允许出现在上表列出的三处强调位；新增设计时先想"这条线是否必要"，多余即删

### 分页面的特殊约定

计划分页（`plan/`）的内容区不设上下框线，直接以留白分隔，保持轻盈；主页各模块维持原设计。

## 发布方式

本仓库使用 **GitHub Pages** 从 `main` 分支根目录自动部署：

1. 修改本地文件并提交
2. 推送到 `main` 分支
3. 网站约 1–2 分钟内自动更新（无需任何手动操作）

## 技术说明

- 纯静态 HTML/CSS/JS，无框架、无构建步骤，任何编辑器均可修改
- 所有分页面复用主页的样式与组件，改一处样式全站生效
- 使用相对路径引用资源，域名或路径变更不影响页面
