# pcpths

Website of Photography Club of Putuo High School（普陀中学摄影社官方网站）

线上地址：<https://kylinle.github.io/pcpths/>

## 目录结构

```
├── index.html          # 首页（结构与内容）
├── css/
│   └── style.css       # 全部样式
├── js/
│   └── main.js         # 交互脚本
└── assets/
    └── favicon.svg     # 网站图标
```

## 发布

仓库使用 GitHub Pages，从 `main` 分支自动部署。将改动 push 到 `main` 后，网站约 1–2 分钟内自动更新。
